# Portafolio de Adrián

Portafolio estático creado con HTML, CSS y JavaScript vanilla.

## Personalización rápida

- Cambia el nombre, textos, enlaces y correo directamente en `index.html`.
- Sustituye cada placeholder por tus fotos en `assets/` usando estos nombres:
  - `adrian-retrato.jpg`
  - `proyecto-01.jpg`
  - `proyecto-02.jpg`
  - `proyecto-03.jpg`
- Para mostrar una imagen real, reemplaza el contenido del bloque `.media-placeholder` por una etiqueta `<img>` y conserva la clase `portrait-placeholder` o `project-image`.

## Ejecutar

Desde esta carpeta:

```bash
python -m http.server 4173
```

Abre `http://localhost:4173/`.
